## Design contract (build exactly this)

In `slim_llm_memory/rerank.py`:

```python
RERANK_MARGIN = <a sensible default, strictly between 0.0 and 1.0>

def should_rerank(scores: "Sequence[float]", margin: float) -> bool:
    """True when the top of the ranking is contested enough to be worth a reranker call."""
```

Semantics, exactly:
- `scores` are the fused ranking scores of a candidate pool, already sorted best first.
  Their absolute scale varies by retrieval mode, so the decision must be scale-free.
- Let `gap = scores[0] - scores[1]` and `spread = scores[0] - scores[-1]`.
  The relative gap is `gap / spread`; a `spread` of 0 counts as a relative gap of 0.0
  (a flat pool is maximally contested).
- Return `True` (do rerank) when `relative_gap < margin`; return `False` (skip) otherwise.
  A lead exactly equal to the margin therefore counts as clear and skips.
- Fewer than two scores, or an empty sequence → `False` (nothing to reorder).
- Return a real `bool` — not `numpy.bool_`, not a truthy float. Callers compare with `is True`.

Scope: the pure function and the constant only. Do NOT wire it into `Topic.ask`; a later
milestone does that. Do not touch `topics.py` or `libraries.py`.
